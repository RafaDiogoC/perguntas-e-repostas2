# 📚 Perguntas e Respostas

---

## 🧠 Lógica de Programação

**P:** O que é uma variável?  
**R:** É um espaço na memória usado para armazenar dados que podem mudar durante a execução do programa.

**P:** O que é um loop?  
**R:** Uma estrutura que permite repetir um bloco de código várias vezes.

---

## ☕ Java

**P:** O que é a JVM?  
**R:** JVM significa Java Virtual Machine. Ela executa o bytecode Java em qualquer sistema operacional.

**P:** Qual a diferença entre `==` e `.equals()` em Java?  
**R:** `==` compara referências (endereços de memória), enquanto `.equals()` compara o conteúdo dos objetos.

---

## 🌿 Git

**P:** O que é `git clone`?  
**R:** É o comando usado para copiar um repositório remoto para sua máquina local.

**P:** Para que serve `git commit`?  
**R:** Ele salva as mudanças feitas no código localmente no repositório Git.
